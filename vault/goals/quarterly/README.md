# goals/quarterly/

Quarterly goals — written at the start of each quarter, aligned with annual goals.

## Naming Convention

`YYYY-QN.md` — e.g. `2026-Q1.md`, `2026-Q2.md`

## What Goes Here

Concrete goals for the next 3 months, broken down from annual goals. Reviewed and reset at the start of each quarter using the `/goals` skill.

## Categories

Use any combination of: Work, Health, Learning, Personal — or define your own.

## Frontmatter

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `quarter` | string | yes | e.g. `2026-Q1` |
| `type` | string | yes | always `quarterly-goals` |
| `created` | date | yes | when goals were set |
