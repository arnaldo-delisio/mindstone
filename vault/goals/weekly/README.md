# goals/weekly/

Weekly goals — written at the start of each week during `/shutdown`.

## Naming Convention

`YYYY-WNN.md` — ISO week number format, e.g. `2026-W01.md`, `2026-W52.md`

## What Goes Here

A small set of focused goals for the week, aligned with quarterly goals. Created or updated during the `/shutdown` skill's "plan tomorrow/this week" phase.

## Categories

Use any combination of: Work, Health, Learning, Personal — or define your own.

## Frontmatter

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `week` | string | yes | ISO week, e.g. `2026-W01` |
| `type` | string | yes | always `weekly-goals` |
| `created` | date | yes | when goals were set |
| `theme` | string | no | optional one-word/phrase theme for the week |
