# goals/annual/

Annual goals — written once per year, revisited during quarterly reviews.

## Naming Convention

`YYYY.md` — e.g. `2026.md`

## What Goes Here

High-level goals for the year organized by life area. Use these as the north star when setting quarterly and weekly goals. Written or updated at the start of each year using the `/goals` skill.

## Categories

Use any combination of: Work, Health, Learning, Personal — or define your own.

## Frontmatter

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `year` | number | yes | the year (e.g. `2026`) |
| `type` | string | yes | always `annual-goals` |
| `created` | date | yes | when goals were set |
