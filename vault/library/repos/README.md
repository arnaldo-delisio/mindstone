# library/repos/

Notes on open-source repositories, tools, and codebases you've explored.

## Naming Convention

Use the repo slug: `ripgrep.md`, `react.md`

## What Goes Here

Capture why the repo is interesting, how it works, and what you learned from it. Useful for tracking tools in your workflow or research into how systems are built.

## Frontmatter

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `type` | string | yes | always `learning` |
| `title` | string | yes | repo name |
| `date` | date | yes | date you explored it |
| `tags` | array | yes | topic tags |
| `source` | string | yes | always `repo` |
| `url` | string | no | GitHub/GitLab URL |
| `author` | string | no | author or org name |
| `intelligence_status` | string | yes | `pending` until pipeline runs |
