# reviews/weekly/

Weekly review notes — written automatically by Claude during `/shutdown` when 7 days have passed since the last review.

## Naming Convention

`YYYY-MM-DD.md` — the date the review was written, e.g. `2026-01-07.md`

## What Goes Here

A conversational weekly review covering what happened, what you learned, and what needs attention next week. Generated by Claude during the `/shutdown` skill's Week Pulse phase. You do not write these manually.

## Frontmatter

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `date` | date | yes | review date |
| `period_start` | date | yes | start of the week covered |
| `period_end` | date | yes | end of the week covered |
| `goals_hit` | string | no | e.g. `3/5` |
| `type` | string | yes | always `review` |
| `tags` | array | yes | always `[review]` |
